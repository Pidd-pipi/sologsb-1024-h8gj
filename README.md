# 光影谱 · 灯光演出提示设计台

面向灯光设计、编程与舞台监督的演出提示工作台。按场次维护通道、灯位、颜色、亮度、渐变、跟随关系和备注，并在拖动顺序后自动重算时间、提示通道或逻辑冲突。

## 功能

- 多方案数据模型；每个方案包含多个场次，每个场次包含完整灯光提示。
- 按场次维护灯位、控制通道、颜色、色值、亮度、渐入、保持、渐出、跟随目标、触发动作、备注和执行状态。
- 使用鼠标或键盘拖动提示排序；每次排序、参数应用或删除后自动重算全剧时间。
- 自动检测同通道叠光、跟随目标不存在或顺序异常、缺失通道/灯位、亮度越界、灯位重复等问题。
- 多个方案并排比较，按场次顺序显示提示时间、通道和亮度。
- 可冻结已确认场次；冻结后提示参数与排序只读，舞台监督或灯光设计可解除冻结。
- 未完成提示快捷跳转；`Alt+N` 可在所有未确认或存在阻断冲突的提示间循环移动。
- 角色权限：灯光设计可完整编辑，编程执行可调整参数，舞台监督可冻结场次，只读角色只能查看。
- 离线草稿自动写入 `localStorage`，模拟保存接口展示在线/离线同步状态。
- 最多 50 步撤销重做；快捷键包括 `↑/↓` 选择提示、`F` 冻结/解冻、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 重做、`Ctrl/⌘+S` 保存。
- 时间轴、提示列表、复选关系图和冲突面板均提供语义标签、焦点样式和读屏描述。
- 导出当前方案 JSON，便于制作交接与外部备份。

## 技术栈

- React + TypeScript
- Vite
- Chakra UI
- dnd-kit（鼠标与键盘排序）
- localStorage
- 无后端服务，全部数据在浏览器本地处理

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码没有硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

生产产物生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1024 .
docker run --rm -p 10024:80 sologsb-1024
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10024`。

## 数据说明

方案、提示、冻结状态、角色选择和草稿都保存在当前浏览器。清除站点数据会删除本地设计稿，重要方案请导出 JSON 备份。
